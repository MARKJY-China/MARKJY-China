### [XuanTie-Lang · 玄铁](https://github.com/MARKJY-China/XuanTie-Lang)

A systems language whose keywords are single Chinese characters.

- self-hosting LLVM compiler; the stage-2 build is byte-identical to stage-1
- no GC — atomic ARC, and cycles stay the programmer's problem
- native async, not bolted on afterwards
